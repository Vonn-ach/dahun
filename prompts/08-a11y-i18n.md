# Prompt 08: Accessibility + Bahasa Malaysia

```
READ FIRST: CLAUDE.md (coding rules), docs/PEDAGOGY.md (neuro-inclusive design), src/i18n/, docs/PROGRESS.md.

GOAL: The app is comfortable for keyboard users, screen-reader users, people with low vision and neurodivergent learners, and is fully usable in Bahasa Malaysia.

BUILD:
1. Audit every screen with axe (add @axe-core/playwright to the e2e tests) and fix all serious and critical issues.
2. Focus management: move focus to the new exercise heading on each step. Feedback is announced through an aria-live region. Dialogs trap focus and Esc closes them.
3. Indigenous-language text is marked with lang="<iso>" (e.g. lang="xkl") so screen readers don't mispronounce it as English. UI text uses lang="en" or lang="ms".
4. Contrast: all text at least 4.5:1 and large text at least 3:1, in both themes. Add a test that checks token pairs.
5. Larger text setting (about 1.2×) and respect for the OS font size. Nothing clips at 200% zoom on a 360px screen.
6. Translate every UI string into Bahasa Malaysia (src/i18n/ms.json). Keep the tone plain and friendly, not formal or bureaucratic. List any phrase you are unsure of in docs/ms-review.md (key, your BM, the English) for a native BM speaker to check.
7. First-run onboarding (3 short screens, skippable): interface language → which variety (the pack's selectable dialects + "Not sure"; skip this screen while only one variety has content) → round length. Then straight into Lesson 1.

CONSTRAINTS:
- Do not translate or touch indigenous-language content. Only UI strings.

ACCEPTANCE:
- axe finds 0 serious or critical issues in e2e runs. The whole app works with Tab/Enter/Space/Esc only.
- Switching to BM changes every UI string, and nothing falls back to English.

FINISH: Update docs/PROGRESS.md and commit ("feat: a11y pass + Bahasa Malaysia UI").
```
